# 标题雷达

一个基于 DeepSeek API 的本地视频发布助手。上传视频可在浏览器本地读取时长与画面节点，粘贴字幕后可完成：

- 提炼 3–5 个有字幕依据的内容卖点
- 分别生成 10 个抖音标题和 10 个哔哩哔哩标题
- 按平台权重评估钩子、清晰度、内容匹配、搜索发现、好奇心和夸大风险
- 自动排序并突出每个平台的 Top 3
- 生成封面大字、简介、标签、置顶评论和发布时间建议

## 本地启动

```powershell
npm install
npm run dev -- --host 0.0.0.0
```

浏览器打开 <http://localhost:3000/>，在右上角“API 设置”中填写自己的 DeepSeek API 密钥。密钥只保存在当前浏览器的本地存储中，分析请求不会上传视频文件。

Windows 用户也可以双击项目根目录中的 `启动标题雷达.bat`。

## 使用边界

分析只依据用户提交的字幕，不会声称理解未提供的音频。所有评分都是编辑辅助判断，不是平台官方评分，也不保证流量。发布前请核对事实、数字、资质和引用来源。
